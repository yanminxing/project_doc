# 1 JS的基础知识

## 1.1  数据类型

1  数据类型有哪些？

> JavaScript数据类型可以分为两类：基本数据类型（原始类型）和引用数据类型（对象类型）。JavaScript的基本数据类型有7种，分别是Number、String、Boolean、Null、Undefined、Symbol（es6新增，表示独一无二的值）和BigInt（es10新增）；引用数据类型有一种，即Object。JavaScript不支持任何创建自定义类型。

2 值的存储

> 基本数据类型：基本数据类型存储在栈（stack）中，占据空间小、大小固定，属于被频繁使用数据，所以放入栈中存储。
>
> 引用数据类型：同时存储在栈（stack）和堆（heap）中，占据空间大、大小不固定。引用数据类型在栈中存储了指针（地址），该指针指向堆中对应的对象。如果变量x指向一个对象，则代码let y = x;执行后，变量y保存的是同一个对象的引用，而不是该对象的副本。通过变量y对这个对象所做的任何修改，在变量x上都是可见的。
